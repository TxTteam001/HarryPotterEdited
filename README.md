# 职业

职业名称|技能01|技能02|
--------|------|-------|
哈利|使用隐身斗篷隐身。|无|
赫敏|使用时间转化器倒退自己的时间，如果被非咒语所击杀会复活。|无|
罗恩|使用防御式决斗来防止自己被击杀，使用期间无法移动。|无|
伏地魔|使用阿瓦达索命咒进行击杀。|无|
贝拉|使用夺魂咒控制他人。|使用钻心刻骨咒使玩家失明并动弹不得。|
